# Optional two-line user CLAUDE.md snippet

Install only when you want automatic reminders in every session. Remember that custom subagents also inherit user and project CLAUDE.md files.

```md
When I ask to delegate, use tandy-terra, tandy-terra-worktree, or tandy-terra-readonly; keep unique names and agent IDs. Redirect an existing worker with SendMessage instead of replacing it when the task evolves.
```

The kit does **not** install this by default because even a small global rule is repeated in every custom subagent context.
